# AI-07 E-03 실제 DB 설명문 평가

## 1. 평가 목적

실제 공통 DB에서 조회한 설명문에 대해 내부 Ollama가 생성한
수정 제안이 기존 보수적 문장 검사 규칙에 부합하는지 확인한다.

## 2. 평가 환경

- 평가일: 2026-10-29
- 데이터: 공통 MySQL DB, run_id=1의 상위 후보 5건
- 모델: 내부 Ollama exaone3.5:7.8b
- 검사 기준: E-03 conservative_phrase_allowlist_v1
- DB 접근: 읽기 전용

## 3. 평가 결과

| 검증 항목 | 결과 |
|---|---:|
| 평가 대상 | 5건 |
| Ollama 호출 성공 | 5건 |
| 수정문 수용 | 0건 |
| 원문 복원 | 5건 |
| unsupported_change | 5건 |
| DB 변경 | 0건 |

## 4. 주요 발견

- 다섯 수정 제안 모두 현재 허용 표현 범위를 벗어나 원문으로 복원되었다.
- 일부 제안에서는 실행 번호가 누락되었다.
- 한 제안에서는 점수 79.6422가 79.642로 변경되었다.
- 모든 수정문이 거부되었으므로 자연스러운 문장 개선의 수용 성능은 확인되지 않았다.

## 5. 검증 범위와 한계

- 이 결과는 실제 DB 설명문에 E-03의 보수적 검사 규칙을
  별도 평가 스크립트에서 적용한 결과이다.
- 기존 refine_card()는 가상 E-02 카드 전용이며,
  실제 DB 데이터용 운영 경로가 완성되었다는 의미는 아니다.
- 원문 복원 결과는 확인했지만 모든 가능한 오류를 검출했다는 뜻은 아니다.
- 개별 원문과 Ollama 제안문이 포함된 CSV는 저장소에 업로드하지 않았다.
- 최종 운영 적용과 병합은 팀 검토 후 진행한다.
