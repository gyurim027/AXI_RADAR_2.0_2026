# 실행 방법

기준: 팀의 feature/w05-llm 공통 코드가 있는 프로젝트. Python 3.11~3.13 및 uv 사용.
공통 코드·설정은 덮어쓰지 않고 이 제출본의 app, tests, samples, scripts, docs 폴더를 저장소 루트에 합칩니다.
다른 팀 파일과 같은 경로가 있으면 내용을 비교해 합칩니다. 이 ZIP을 저장소 안의 별도 중첩 폴더로 올리지 않습니다.
기존 backend/ai07/ 폴더 삭제는 이번 제출에서 수행하지 않습니다.

공통 프로젝트 폴더의 PowerShell에서:

```powershell
uv sync --python 3.12 --group dev
uv run python -m pytest tests/test_ai07_synthetic_api.py tests/test_ai07_api.py tests/test_ai07_read_only_db.py tests/test_e02.py tests/test_e03.py tests/test_f06.py tests/test_h04.py -q
uv run uvicorn app.main:app --host 127.0.0.1 --port 8000
```

서버 창은 켜 둡니다. 다른 PowerShell에서 같은 프로젝트 폴더로 이동한 후:

```powershell
uv run python scripts/ai07_server_smoke.py
```

네 줄 모두 HTTP 200인지 확인합니다. 가상 시험에는 DB 비밀번호나 AI 키가 필요하지 않습니다.
브라우저 http://127.0.0.1:8000/docs 에서 새 POST 주소를 확인할 수 있습니다:
- /api/ai07/synthetic/explanation
- /api/ai07/synthetic/refine
- /api/ai07/synthetic/request
- /api/ai07/synthetic/report

공통 응답 규칙으로 출력 키는 camelCase입니다. 가상 JSON 입력 키는 samples 파일 그대로 사용합니다.
로컬 Host/Origin 제한은 실제 로그인 대체가 아닙니다. 이번 시험 서버는 127.0.0.1에서만 실행합니다.
깃허브에는 feature/ai-07 작업 공간에 변경 파일을 올리고, 공통 코드와의 병합은 팀 절차에 따릅니다.
