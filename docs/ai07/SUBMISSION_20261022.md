# AI-07 개인 과제 제출 — 2026-10-22

제출 상태: 가상 자료 기반 문장 틀 구현 및 공통 FastAPI 연결 검증본.
실제 LLM·DB 자료를 연결한 최종 완성본은 아닙니다.

## 포함한 작업
- E-02: 제공된 가상 근거 카드로 기본 설명문 생성. 근거 누락과 0을 구분.
- E-03: 허용된 표현 변경만 검사. 숫자 등 허용하지 않은 변경은 기본 문장으로 복구.
- F-06: 가상 확정 대상·담당 부서·검토된 조치 제안을 받아 관할 요청안 초안 생성. 발송하지 않음.
- H-04: 가상 회차·관할 자료로 현황 / 데이터 근거 / 관련 기준 / 데이터로 모르는 것 / 조치 제안 구성의 연간 검토보고서 문장 틀 생성.
- 공통 서버에 위 네 기능의 가상 자료 POST 주소 연결. 기존 AI07 조회 주소 유지.

E-03은 제한된 표현 변경 검사이며 일반적인 LLM 결과의 사실 검증을 완성한 것은 아닙니다.
입력의 확정·검토 표식과 관할 범위는 가상 시험용 값입니다. 실제 승인·로그인·권한을 검증하지 않습니다.

## 확인 기록
사용자가 Windows의 공통 프로젝트에서 실행하여 공유한 결과:
- AI07 관련 pytest: 70 passed, 1 warning, 36 subtests passed in 1.47s
- 실제 로컬 서버 연결 스크립트: explanation / refine / request / report 모두 HTTP 200
- 입력 자료는 synthetic 가상 자료이며 실제 LLM 호출·실제 DB 연결 성공의 증거가 아닙니다.
- 경고 세부 내용은 전달받지 않아 이 문서에서 원인을 확정하지 않습니다.
