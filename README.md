# RADAR 2.0

성남시 보도 정기 점검의 우선순위를 제안하는 도구입니다.
민원을 처리하는 도구가 아닙니다. 먼저 점검할 곳을 고르는 참고 순위를 보여 줍니다.

## 누가 쓰나요

| 사용자 | 하는 일 |
|---|---|
| 구 도로관리팀 | 점검 후보를 보고 우선 점검 대상을 정합니다 |
| 시 도로과 | 3개 구의 후보와 확정 현황을 봅니다 |
| RADAR 운영자 | 기준정보와 데이터를 관리합니다 (어드민) |

## 핵심 흐름

점검 후보 보기 → 근거 확인 → 점검 여부 결정 → 우선 점검 대상 확정 → 보고서 받기

## 이 저장소

| 폴더 | 내용 | 상태 |
|---|---|---|
| `frontend/` | 화면 (React). 실행 방법은 `frontend/README.md` | 사용자 화면 가안 완료, 어드민 예정 |
| 백엔드 | Python | 아직 없음 |

기준 문서는 기능정의서 최신 버전입니다. 화면은 이 문서에 적힌 것만 만듭니다.
