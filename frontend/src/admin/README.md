# 어드민

RADAR 운영자 화면(AD-00~AD-17)입니다. 기준은 기능정의서 최신 버전의 `10_3_화면명세_어드민`입니다.

```
admin/
├─ layout/       공통 상단(AD-00): 상단 바, 보조 탐색, 알림, 사용자 화면 보기
├─ components/   어드민 부품 (버튼, 표, 대화상자, 입력창 …). 사용자 화면 부품과 토큰이 달라 따로 둔다
├─ features/     화면 묶음. 묶음마다 pages와 copy.js(화면 문구)
│  ├─ dashboard/   AD-01
│  ├─ data/        AD-02~05 데이터 목록, 업로드, 검사 결과, 분류 검수
│  ├─ runs/        AD-06~08 회차 목록, 실행 기록, 실행 일정
│  ├─ standards/   AD-09~14 산정 기준, 담당 부서 표, 규정 변경, 조치 제안 표, 승인 이력
│  └─ settings/    AD-15~17 계정, 접속 기록, 알림 설정
├─ routes.jsx    주소 목록
└─ copy.js       공통 상단 문구
```

- 색·간격은 `src/styles/admin-tokens.css`(`--radar-admin-*`)와 `admin-alias.css`(`--a-*`)만 씁니다.
- 어드민은 결정·확정·승인을 하지 않습니다. 승인 요청까지만 하고, 승인은 시 도로과 화면(승인 대기)에서 합니다.
- 원문 열람(AD-05)은 확장 단계라 만들지 않았습니다.
