# 가짜 서버와 데이터

백엔드가 생기기 전까지 화면이 쓰는 데이터입니다. 화면은 `src/api/`만 부르고 이 폴더를 직접 부르지 않습니다.

- `server.js`: 가짜 서버. 역할별로 걸러 내리기, 결정 저장 규칙, 구 확정, 보고서 데이터
- `generate.js`: 후보 가짜 데이터 생성기. 같은 코드는 항상 같은 결과를 냅니다
- `data/seongnam_cells.json`: DB v1.9 `01_grid_cell`에서 뽑은 격자 위치(번호, 중심 좌표, 구, 동)와 구 경계(볼록 껍질). 이 파일 밖의 값은 모두 가짜입니다
- `store.js`: 결정과 구 확정을 브라우저(localStorage)에 남깁니다
- `adminData.js`: 어드민 처음 값(데이터 목록, 실행 기록, 산정 기준 버전, 규정 변경 …). 기능정의서 어드민 화면명세의 예시 문구를 바탕으로 했습니다
- `adminModel.js`: 어드민에서 바꾼 값이 사용자 화면으로 이어지는 곳(회차, 계정, 데이터 목록, 승인 대기, 조치 제안 표)
- `adminServer.js`: 어드민 가짜 서버. RADAR 운영자만 부를 수 있습니다

## 어드민 가짜 규칙 (개발 장치)

- 지금 날짜는 2026.11.20 15:00에서 시작해 화면을 연 뒤 지난 시간만큼 흐릅니다.
- 파일 이름에 `오류`나 `error`가 들어 있으면 올릴 때 검사에서 3건이 걸립니다.
- 산정은 3초 뒤에 끝납니다. `보도 폭 측정 자료`가 빠져 있으면 실패합니다. 올린 뒤 다시 실행하면 성공합니다.
- 산정 기준 변화 미리 보기의 "바뀌는 곳 수"는 바뀐 값의 크기로 만든 가짜 값입니다.
- 새 계정의 비밀번호는 `radar1234`입니다.
